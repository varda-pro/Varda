# Menu icons

Font Awesome Free 6 solid icons (https://fontawesome.com), licensed
CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/), recolored to a
mid gray (#808080) that reads on light and dark menus.

They are bundled so that Varda never fetches icons at run time: superqt's
iconify icons asked api.iconify.design on every launch, even offline.
Add a new icon as an SVG file here and refer to it with
`varda.utilities.resources.bundledIcon("<name>")`.
